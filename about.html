About PrintSizer

PrintSizer is a small collection of free, browser-based calculators for people who prepare images for print, web and product production: print shops, Etsy sellers, designers, photographers and anyone who has ever asked "what size will this image print?"

How the tools work

Every calculator runs entirely in your browser with JavaScript. No account, no file upload, no server storage. The maths used is explained on each page so you can check the result yourself.

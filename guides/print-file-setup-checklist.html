Print File Setup Checklist

Most print problems are not printing problems - they are file setup problems. Run through this checklist before sending anything to a commercial printer and you will avoid rejected files, unexpected crops and colour surprises.

1. Document size and bleed

Create the document at the final trim size plus bleed on every edge. US commercial print usually asks for 0.125 in, European print for 3 mm, and large-format work for 6 mm. An 8.5 × 11 in flyer with 0.125 in bleed is therefore 8.75 × 11.25 in. Use the bleed calculator to confirm your numbers.

2. Safe margins

Keep text, logos and critical artwork at least 0.125–0.25 in (3–6 mm) inside the trim edge, or follow the printer's template. The trim can shift by a millimetre or two during cutting, and content too close to the edge risks being clipped.

3. Image resolution

Check every placed image at its final size. Rules of thumb: 300 PPI for close-up print, 200 PPI for canvas, 150 PPI for posters and 75–100 PPI for large backdrops. A high-resolution JPEG that has been scaled up in the layout program is still low resolution - check the effective PPI rather than the file's dimensions on disk.

4. Colour mode and profiles

Digital printers usually accept RGB files and convert them. Offset printers often ask for CMYK with a specific profile. Convert once, at the end, and ask for a proof if colour accuracy matters. Avoid building designs around neon or highly saturated screen colours that lie outside the CMYK gamut.

5. Fonts

Either embed all fonts in the PDF or convert text to outlines. Converting to outlines guarantees the appearance but makes the text uneditable, so keep an editable master file and export a separate outlined version. Check that no font has been substituted silently.

6. Vector artwork

Logos, icons and line art should remain vector (AI, EPS, SVG or vector PDF content) so they stay sharp at any size. Raster logos need to be supplied at the pixel dimensions required by the largest product in the order.

7. Export settings

  • PDF: embed fonts, include bleed, use crop marks if requested, downsample images to the target PPI rather than below it.
  • JPEG: maximum quality, correct pixel dimensions, sRGB unless told otherwise.
  • TIFF: lossless, suitable for photo products; expect large files.

8. Final pre-flight checklist

  1. Document size = trim size + bleed on all sides.
  2. Backgrounds extend fully into the bleed area.
  3. Text and logos inside the safe margin.
  4. All images at or above the required effective PPI.
  5. Colour mode matches the printer's instruction.
  6. Fonts embedded or outlined; no missing links.
  7. Export opens correctly and page count/orientation is right.
  8. The file name makes it obvious that this is the final version.

Common reasons files get rejected

  • No bleed on an edge-to-edge design.
  • Low-resolution images that looked fine on screen.
  • RGB artwork submitted for a job that explicitly required CMYK.
  • Text too close to the trim edge.
  • Missing fonts or linked images.
  • Wrong page size - for example designing at A4 for a US Letter job.

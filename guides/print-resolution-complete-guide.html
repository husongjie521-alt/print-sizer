Print Resolution: The Complete Guide

Print resolution is the single most misunderstood part of preparing files for print. This guide explains what DPI and PPI actually mean, how to calculate the pixels you need for any product, and when a lower resolution is perfectly acceptable.

DPI and PPI: what is the difference?

PPI (pixels per inch) describes how many pixels of a digital image fit into one inch. DPI (dots per inch) describes how many ink dots a printer places in one inch. In everyday print workflows the two terms are used interchangeably, and most print services quote "DPI" when they mean the pixel density of your file.

What matters for print is simple: the pixel dimensions of your image and the physical size you want to print. The DPI value saved in the file's metadata is just a label; changing it does not add or remove detail.

The only formula you need

Pixels = print size in inches × DPI

To go the other way: print size in inches = pixels ÷ DPI. A 6000 × 4000 px image printed at 300 DPI gives 20 × 13.3 inches. The same file at 200 DPI gives 30 × 20 inches, and at 150 DPI it gives 40 × 26.7 inches.

When lower resolution is fine

Resolution requirements depend on viewing distance. The further away a print is viewed, the fewer pixels per inch the eye can resolve. Large posters are commonly printed at 150 DPI, event backdrops at 75–100 DPI, and billboards at 10–30 DPI. If you are unsure, use the poster DPI calculator to get a recommendation based on distance.

How to check whether a file is good enough

  1. Find the pixel dimensions (Windows: right-click → Properties → Details; macOS: Preview → Tools → Show Inspector).
  2. Divide each dimension by the product's required DPI.
  3. Compare the result with the product size. If the calculated size is smaller than the product, the file is below the target resolution.
  4. Repeat with a lower DPI if the print will be viewed from a distance.

The print PPI calculator does this automatically for any combination of pixels and print size.

Four common myths

  • "72 DPI is low resolution." The 72 DPI tag is metadata. A 4000 × 3000 px file tagged 72 DPI still prints at 13.3 × 10 inches at 300 DPI.
  • "More DPI always means better." Beyond the printer's ability and the eye's limit, extra resolution only increases file size.
  • "Upscaling fixes a small file." Interpolation invents pixels but cannot recover detail that was never captured.
  • "File size in MB tells you the resolution." JPEG compression means two files with identical dimensions can differ hugely in megabytes.
